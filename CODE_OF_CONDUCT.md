# OpenNexus Code of Conduct

---

## 1. Our Pledge

We are committed to fostering an open, welcoming, and inclusive community across the OpenNexus ecosystem. Everyone is entitled to participate free from harassment, discrimination, and hostility, regardless of background, identity, skill level, or role.

OpenNexus is built on collaboration, technical curiosity, and mutual respect. We expect all contributors and participants to uphold these values across all project touchpoints.

---

## 2. Standards of Collaboration

We encourage thoughtful, candid, and constructive interactions. When participating in OpenNexus:

* **Critique the architecture, not the person**: Focus discussions on code design, benchmark evidence, bug reproduction, and engineering trade-offs. Technical debates are welcome; personal disparagement is not.
* **Preserve privacy and data sovereignty**: OpenNexus is a local-first application built around user trust. Never expose private vault contents, credentials, system paths, telemetry logs containing personal data, or private communication without consent.
* **Respect intellectual property and licensing**: Honor the terms of open-source licenses, datasets, and third-party model weights. Provide appropriate attribution for upstream libraries and community contributions.
* **Assume good faith, verify with facts**: Give collaborators the benefit of the doubt while maintaining rigorous engineering standards through reproducible test cases, verifiable benchmarks, and clear documentation.
* **Respect project governance**: Maintainers are responsible for architectural direction, stability, and security boundaries. Accept triage, scope limits, and moderation decisions constructively.

---

## 3. Unacceptable Behavior

The following actions violate our community standards and will not be tolerated:

* **Harassment and abuse**: Personal attacks, derogatory comments, trolling, discriminatory slurs, or sexualized language.
* **Doxxing and data leaks**: Publishing another person’s private information, API credentials, real-world contact details, or internal server configurations.
* **Malicious disruption**: Spamming issue trackers, automating abusive requests, circumventing CI/CD protections, or attempting to sabotage project infrastructure.
* **Misrepresentation and fraud**: Plagiarism, spoofing git commit authorship, falsifying benchmark data, or misrepresenting community plugin safety.
* **Coercion**: Pressuring contributors, users, or maintainers into revealing private infrastructure or sharing confidential access keys.

---

## 4. Scope

This Code of Conduct applies to all spaces managed by or representing the OpenNexus project, including:

* The primary repository and associated ecosystem repositories (`Sync-for-OpenNexus`, `Community-for-OpenNexus`).
* GitHub Issues, Discussions, Pull Request reviews, and release notes.
* Community plugin and skill registry submissions.
* Official chat channels, social media representations, and project meetups.

---

## 5. Enforcement & Escalation

Community maintainers follow a proportional enforcement ladder to resolve violations:

| Enforcement Tier | Description | Action |
| --- | --- | --- |
| **1. Correction** | Minor or unintentional breach of etiquette (e.g., impolite tone, non-redacted log). | Private or public note from a maintainer clarifying community standards; request to redact or edit content. |
| **2. Warning** | Repeated violations or noticeable disrespect toward others. | Formal written warning; comment or thread locked; offending content removed. |
| **3. Temporary Restriction** | Serious infraction, persistent harassment, or disruptive behavior. | Temporary ban from repository interactions (Issues, PRs, Discussions) for a defined period (e.g., 7–30 days). |
| **4. Permanent Expulsion** | Severe violations, malicious intent, doxxing, or repeated disregard for warnings. | Permanent block from all OpenNexus repositories, organizations, and community distribution registries. |

---

## 6. Reporting Guidelines

If you experience or witness behavior that violates this Code of Conduct, report it promptly:

* **General Conduct Violations**: Contact the maintainers via the repository moderation tools or reach out directly to the maintainers listed on GitHub.
* **Security & Vulnerability Reports**: Do **not** post security bugs, exploit chains, or leaked tokens in public issues. Submit them privately via [GitHub Private Vulnerability Reporting](https://www.google.com/search?q=https://github.com/KiriAky107/OpenNexus/security/advisories/new&utm_source=gemini).

All reports will be handled with discretion and confidentiality. Retaliation against anyone reporting a violation in good faith will be treated as an immediate Tier 4 violation.
